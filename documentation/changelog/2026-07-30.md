# Catatan Perubahan (Changelog) - 30 Juli 2026

## 🚀 Fitur Baru & Perbaikan UX Homepage, Navigasi, Single Post Page, dan AdSense Slot

### 📌 Ringkasan Perubahan:
1. **Homepage Category Bar & Filter 0-Artikel**:
   - Menyamakan label tombol pertama ke bahasa aktif ("Semua" dalam mode Bahasa Indonesia / "All" dalam mode Bahasa Inggris) via [locales.js](file:///c:/web/scholarcms/src/constants/locales.js).
   - Menyembunyikan scrollbar pada baris navigasi kategori dengan kelas CSS `no-scrollbar scrollbar-none`.
   - Menyaring kategori pada seluruh tema ([Modern](file:///c:/web/scholarcms/src/themes/modern/index.jsx), [Editorial](file:///c:/web/scholarcms/src/themes/editorial/index.jsx), [Minimalist](file:///c:/web/scholarcms/src/themes/minimalist/index.jsx)) agar kategori dengan 0 artikel terpublikasi disembunyikan secara otomatis.

2. **Pembaruan Widget Kategori, Tag, & Random Articles ([TrendingTopicsWidget.jsx](file:///c:/web/scholarcms/src/components/blog/TrendingTopicsWidget.jsx))**:
   - **CategoryTopicsWidget**: Kategori berpengisi (> 0 artikel) ditampilkan dalam format *tag pills* (`flex flex-wrap gap-1.5`) yang rapi, dibatasi jumlahnya, dan urutannya diacak.
   - **TrendingTagsWidget**: Tag dari artikel terbit disaring (> 0 artikel), urutan diacak, dan style badge diperbarui tanpa sudut kaku `rounded-xl`.
   - **RandomArticlesWidget**: Membuat komponen widget artikel acak (*Random Articles*) baru yang dilengkapi tombol acak ulang (*shuffle*).

3. **Perbaikan Kepekaan Hover Navbar Dropdown ([Navbar.jsx](file:///c:/web/scholarcms/src/components/layout/Navbar.jsx))**:
   - Menambahkan *hover bridge* (`before:` area) dan delay timeout (200ms) pada handler `onMouseLeave`, mencegah menu dropdown level 2 dan level 3 tertutup secara prematur saat kursor berpindah.
   - Memperbaiki deklarasi state `activeL1` dan `activeL2` untuk mengeliminasi `ReferenceError`.

4. **Single Post Page (`/post/[slug]`) Layout 2-Kolom**:
   - **Grid Layout**: Mengubah halaman post menjadi layout 2-kolom responsif (`grid grid-cols-1 lg:grid-cols-12 gap-8`), dengan 8 kolom untuk artikel utama dan 4 kolom untuk Sidebar Rekomendasi di kanan.
   - **Breadcrumb Navigation**: Menambahkan navigasi Breadcrumb (`Beranda > Kategori > Judul Artikel`) di bagian atas beserta Schema.org `BreadcrumbList` JSON-LD untuk SEO dan AdSense.
   - **Navigasi Postingan**: Menambahkan kartu navigasi ke Artikel Sebelumnya (*Previous Post*) dan Artikel Selanjutnya (*Next Post*).
   - **Wrap Tag Display**: Menata tag postingan secara *wrap* (`flex-wrap gap-2`) tanpa scrollbar horizontal.
   - **Sidebar Rekomendasi (Samping Kanan Artikel)**: Menempatkan kartu rekomendasi di sisi kanan postingan (Artikel Terkait, Artikel Populer, Artikel Acak, dan Widget Topik/Tag).

5. **Pengendalian Slot AdSense ([AdSenseBanner.jsx](file:///c:/web/scholarcms/src/components/blog/AdSenseBanner.jsx))**:
   - Apabila AdSense di-nonaktifkan di Admin Settings (`isEnabled === false`), slot banner AdSense tidak lagi menampilkan kotak placeholder (`return null`).
